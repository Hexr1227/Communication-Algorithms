# 第一课：亲手实现一个时隙的队列

## 课前回顾

你已经口头答对容量、时延、突发/过载和相同轨迹对照的基础题。实践从零开始。先回答：队列只有 1 单位，容量 10 单位，最多发多少？本时隙末到达的数据能否在本时隙发出？

## 本课所需知识

Python 函数参数、返回元组、整数、异常和比较；容量是发送上限，队列是已有数据。离散时钟按步骤推进。事件顺序为服务旧队列、接收新数据。一个时隙的守恒关系是“旧队列 + 新到达 = 发出量 + 新队列”。这说明数据不会凭空增加或消失。你要自己将容量限制和事件顺序转成代码。

## 手算与契约

例：开始队列 3、容量 2、时隙末到达 4。先发 2，旧数据剩 1，再接收 4，最后队列是 5。返回值为 (2, 5)。容量为零时不能发送；旧队列为零时，即使时隙末有到达，本次发送仍为零。

接口和输入错误规则在 student.py。仅编辑 student.py 的函数主体及 reflection.md。不要改测试。先独立写出几个手算结果，再实现；助手只能解释、提示和评审。
